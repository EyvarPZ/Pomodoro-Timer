# 🍅 Pomodoro Timer

Aplicación de escritorio en Python que implementa la técnica Pomodoro para ayudarte a mantener el enfoque.

## Características

- Temporizador con cuenta regresiva en formato MM:SS
- Controles para iniciar, pausar y reiniciar
- Ciclos de trabajo, descanso corto y descanso largo
- Interfaz moderna con el tema **simplex** de ttkbootstrap

## Tecnologías

- Python 3.14
- tkinter
- ttkbootstrap

## Requisitos

- Python 3.10 o superior
- ttkbootstrap
